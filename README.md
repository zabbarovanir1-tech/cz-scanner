# Проверка ЧЗ — сканер кодов Честного знака для ТСД

Android-приложение для терминалов сбора данных (ТСД): сканируете код DataMatrix — и сразу видите статус
кода в системе «Честный знак», как в потребительском приложении:

| Цвет | Что значит |
|---|---|
| 🟩 Зелёный | Код в обороте, всё в порядке |
| 🟥 Красный | Код не найден, не введён в оборот, уже выбыл (продан/списан), заблокирован или истёк срок годности |
| 🟨 Жёлтый | Код найден, но нужен ручной контроль (открыть подробности) |
| ⬜ Серый | Проверить не удалось: нет интернета, ошибка сервера |

Плюс звук (два коротких сигнала — хорошо, низкий гудок — проблема), вибрация, история сканирований,
отметка повторных сканов и отправка списка (Меню → «Отправить список»).

## Установка

1. Откройте вкладку **Releases** этого репозитория и скачайте последний `cz-scanner-*.apk`.
2. Перенесите файл на ТСД (USB-кабель, почта, мессенджер) и откройте его.
3. Если Android спросит — разрешите установку из этого источника.

Новые версии ставятся поверх старых, история сохраняется.

## Подключение сканера

**Режим клавиатуры** — проще всего. В настройках сканера ТСД включите вывод «как клавиатура» и
суффикс Enter. Приложение само поймает код. Если Enter не настроен, код всё равно отправится
по паузе после сканирования.

**Режим Intent / Broadcast** — надёжнее: не теряются служебные символы GS. Поддерживаются автоматически:
Urovo, Newland, Mertech, АТОЛ, iData, Chainway, Sunmi, CipherLab, Point Mobile, Seuic, Unitech, Datalogic.
Если терминал не определился, укажите в настройках сканера:

- Action: `ru.czcheck.scanner.SCAN`
- Extra (ключ данных): `data`

**Zebra (DataWedge):** создайте профиль для приложения `ru.czcheck.scanner` → Intent output: ON,
Intent action: `ru.czcheck.scanner.SCAN`, Intent delivery: Broadcast intent. Keystroke output можно выключить.

Если сканер всё-таки потерял символы GS или печатает в русской раскладке — приложение это исправит
(обе опции включены в настройках по умолчанию).

## Как это работает

Приложение отправляет код на тот же сервер, что и потребительское приложение «Честный знак»
(`https://mobile.api.crpt.ru`), без авторизации и без электронной подписи.
Способ запроса подбирается автоматически (`POST /v2/mobile/check`, `POST /mobile/check`, `GET /mobile/check`)
и запоминается; при необходимости его можно выбрать вручную в настройках.

Ограничения:

- Работает только через российский интернет: из-за рубежа сервер отвечает ошибкой 451.
- Это недокументированный API мобильного приложения: если ЧЗ его изменит, в «Подробностях» будет виден
  ответ сервера — по нему можно быстро поправить разбор.
- Данные о владельце кода (ИНН/организация) публичный API не отдаёт. Для этого нужен True API
  с токеном по УКЭП — можно добавить отдельно.

## Сборка

APK собирается автоматически GitHub Actions при каждом изменении в ветке `main`
(вкладка **Actions** → готовый файл также появляется в **Releases**).

Вручную: откройте папку проекта в Android Studio → Build → Build APK(s).
Или в терминале: `./gradlew assembleRelease` (нужны JDK 17 и Android SDK).

Код:

- `CodeNormalizer.kt` — очистка кода от сканера, восстановление GS, исправление раскладки, разбор GTIN/серийного номера
- `CrptClient.kt` — запрос к серверу Честного знака
- `ResultEvaluator.kt` — превращение ответа в «светофор»
- `ScannerIntents.kt` — приём кодов от сканеров разных производителей
- `MainActivity.kt` — экран
